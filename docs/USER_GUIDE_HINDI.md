# PharmaPOS — विस्तृत उपयोगकर्ता गाइड (हिंदी)

यह गाइड **दुकान मालिक, फार्मासिस्ट और कैशियर** के लिए है। इसमें बताया गया है कि PharmaPOS सॉफ्टवेयर कैसे खोलें, बिल कैसे बनाएँ, खरीद कैसे दर्ज करें, रिटर्न, स्टॉक, हिसाब-किताब और रिपोर्ट कैसे देखें।

आपको कंप्यूटर का गहरा ज्ञान ज़रूरी नहीं है। हर कदम को सरल भाषा में लिखा गया है।

**ध्यान दें:** मेनू और बटन आपके **रोल / अनुमति** के अनुसार दिखते हैं। कोई टैब न दिखे तो एडमिन से अनुमति माँगें।

## 1. सॉफ्टवेयर क्या है?

PharmaPOS एक **विंडोज़ कंप्यूटर** पर चलने वाला मेडिकल स्टोर का बिलिंग और स्टॉक सॉफ्टवेयर है।

इसमें रहता है:

| क्या | सरल अर्थ |
|------|-----------|
| दवाओं की सूची | नाम, साल्ट, GST, बारकोड, रैक/बिन, शेड्यूल |
| बैच वाइज़ स्टॉक | हर बैच की अलग मात्रा और एक्सपायरी |
| सेल बिल | ग्राहक को बेचना, छूट, कैश/UPI/कार्ड/उधार |
| परचेज़ | सप्लायर से माल आना |
| रिटर्न | ग्राहक या सप्लायर को वापसी |
| एक्सपायरी क्लेम | नज़दीक/खराब एक्सपायरी कंपनी को भेजना |
| हिसाब | ग्राहक बाक़ी, सप्लायर पेमेंट, कैश बुक |
| रिपोर्ट | GST, मुनाफ़ा, स्टॉक, शेड्यूल H/H1 आदि |

**ज़रूरी बात:** स्टॉक हमेशा **बैच** पर होता है। बेचते समय एक बैच चुना जाता है (आमतौर पर जल्दी एक्सपायर होने वाला)। खरीदते समय नया बैच बनता या बढ़ता है।

## 2. इंस्टॉल, लॉगिन और स्टोर कोड

### दुकान के कंप्यूटर पर लगाना

1. विक्रेता से मिला **Setup** फ़ाइल चलाएँ (`PharmaPOS-Setup-….exe` या `Install-PharmaPOS-Shop.bat`)।
2. कंप्यूटर **64-bit Windows 10/11** होना चाहिए।
3. पहली बार इंटरनेट चाहिए (डाउनलोड/अपडेट के लिए)।
4. **SQL Server Express LocalDB** ज़रूरी है। अगर ऐप कहे LocalDB नहीं मिला, तो LocalDB इंस्टॉल कर फिर PharmaPOS खोलें।

स्टार्ट मेनू से **PharmaPOS** खोलें।

### पहली बार लॉगिन

| फ़ील्ड | वैल्यू |
|--------|--------|
| Username | `admin` |
| Password | `Admin@123` |

- पासवर्ड **तुरंत बदलें**। लाइव दुकान पर डिफ़ॉल्ट पासवर्ड न छोड़ें।
- अगर पूछे तो नया पासवर्ड दो बार टाइप कर सेव करें।

### स्टोर कोड

पहली बार विक्रेता वाला **स्टोर कोड** डालना पड़ सकता है। सही लिखें — बाद में ऊपर की पट्टी पर दिखता है। अपडेट और रिपोर्टिंग इसी से जुड़ती है।

### बिलिंग काउंटर

एक से ज़्यादा काउंटर हों तो लॉगिन पर **काउंटर** चुनें। दिन का कैश उसी काउंटर से जुड़ता है। बाद में सेल्स स्क्रीन से भी काउंटर बदल सकते हैं।

### डेटाबेस

डेटाबेस ऐप खुलते ही **अपने आप** बनता/अपडेट होता है। सामान्य उपयोग में SQL स्क्रिप्ट चलाने की ज़रूरत नहीं।

## 4. डैशबोर्ड

लॉगिन के बाद होम स्क्रीन (अगर अनुमति हो)।

## 5. सेल्स (बिलिंग) — सबसे ज़रूरी

**सेल्स (F2)** खोलें — यही काउंटर की मुख्य स्क्रीन है।

### स्क्रीन कैसे बँटी है

| हिस्सा | क्या दिखता है |
|--------|----------------|
| बीच / बाईं ग्रिड | दवाएँ, बैच, एक्सपायरी, मात्रा, MRP, सेल रेट, छूट, GST, अमाउंट |
| दायाँ पैनल | ग्राहक, डॉक्टर, पेमेंट, टोटल, Save/Print |
| ऊपर | बारकोड, कैमरा स्कैन, पुराने बिल, रिटर्न, काउंटर, डे क्लोज़ |
| बिल चिप्स | एक साथ कई ग्राहक (`Ctrl+1` … `Ctrl+4`) |

### कदम-दर-कदम: नया बिल बनाएँ

1. **ग्राहक** (वैकल्पिक लेकिन अच्छा है)  
   - नाम और मोबाइल लिखें।  
   - खोज आइकन से पुराना ग्राहक चुन सकते हैं (नाम, मोबाइल, बाक़ी, पता दिखता है)।  
   - **F3** से ग्राहक सेव हो सकता है।  
2. **डॉक्टर** (शेड्यूल H/H1 के लिए अच्छा है) नाम लिखें।  
3. दवाएँ जोड़ें (नीचे देखें)।  
4. पेमेंट चुनें (कैश / UPI / कार्ड / उधार / मिला-जुला)।  
5. **F9** दबाएँ — बिल सेव + प्रिंट प्रीव्यू।

### दवा कैसे जोड़ें

**तरीका 1 — खोज (सबसे आम)**

1. खाली पंक्ति की **Item** सेल पर क्लिक करें या **Enter** दबाएँ।  
2. कम से कम **2 अक्षर** टाइप करें (जैसे `para` या `para500`)।  
3. सूची से दवा चुनें (**Enter**)।  
4. कई बैच हों तो बैच चुनें (जल्दी एक्सपायर वाला ऊपर रहता है)।

खोज विंडो में दिखता है: ब्रांड/नाम, साल्ट, लोकेशन (रैक), Qty, स्केड्यूल, पैक, कॉस्ट, **MRP**, HSN।

**तरीका 2 — बारकोड**

1. बारकोड बॉक्स पर फोकस करें।  
2. स्कैनर से स्कैन करें या नंबर टाइप कर Enter।  
3. या कैमरा बटन से स्कैन करें।

**तरीका 3 — वेबसाइट से नई दवा**

खोज में न मिले तो **Create from website** से 1MG / Apollo आदि से डिटेल लाकर मास्टर में सेव कर सकते हैं।

**अन्य मदद**

| कुंजी / बटन | काम |
|-------------|-----|
| **F5** | वैकल्पिक दवा (समान साल्ट) |
| **F4** | दवा की डिटेल (स्टॉक, रेट, लोकेशन) |
| **Ctrl+L** | दवा का लेजर (खरीद/सेल इतिहास) |

### मात्रा, रेट, छूट

- **Qty** — बेची गई इकाइयाँ; बैच के उपलब्ध स्टॉक से ज़्यादा नहीं।  
- **MRP / Sale** — कीमतें **GST सहित** (भारतीय मेडिकल स्टाइल)।  
- **Disc %** — पंक्ति पर छूट (अनुमति हो तो)।  
- गलत पंक्ति हटाएँ — डिलीट बटन से।

ग्रिड में **Batch**, **Expiry**, **GST %** एडिट हो सकते हैं; **Item नाम** और **Amount** सामान्यतः सिर्फ़ देखने के लिए।

### कई ग्राहक एक साथ (पार्किंग)

| कुंजी | काम |
|-------|-----|
| **Ctrl+T** | नया ग्राहक बिल (नया चिप) |
| **Ctrl+1** से **Ctrl+4** | बिल बदलें |
| **Ctrl+W** | पार्क किया बिल बंद (सेव्ड इनवॉइस नहीं मिटता) |

**ध्यान:** **Esc** से बिल साफ़ नहीं होता — नया बिल बटन से नया शुरू करें।

### पेमेंट कैसे लें

1. डिफ़ॉल्ट अक्सर **Cash** होता है।  
2. **Add payment** से दो तरीके मिला सकते हैं (जैसे कैश + UPI)।  
3. **Credit / उधार** → ग्राहक पर बाक़ी रहेगी; बाद में अकाउंटिंग से वसूलें।  
4. ज़्यादा कैश मिले तो **Change** (वापसी) दिखेगा।

### सेव, प्रिंट, शेयर

1. **F9** → बिल सेव (नंबर जैसे `INV-20260822-0001`)।  
2. प्रीव्यू में कागज़ चुनें: A4 / A5 / 80mm / 58mm → **Print**।  
3. WhatsApp/SMS चालू हो तो सेव के बाद शेयर पूछ सकता है।

सेव के बाद बिल **लॉक** हो जाता है। बदलने के लिए Preferences में एडिट अनुमति + **Unlock** ज़रूरी।

### पुराना बिल दोबारा (F6 — Last Sale / Refill)

1. **F6** दबाएँ।  
2. नाम या मोबाइल से पुराना बिल खोजें।  
3. सूची में ऊपर/नीचे तीर से चुनें।  
4. मात्रा चुनकर कार्ट में लाएँ — रेगुलर पेशेंट के लिए आसान।

### पुराने बिल खोजें

टूलबार से बिल सर्च (मरीज़, मोबाइल, दवा)। खोलकर रीप्रिंट या (अनुमति हो तो) अनलॉक कर एडिट।

### काउंटर और डे क्लोज़

- **Switch counter** — एक PC कई काउंटर पर।  
- **आज का कैश** — कैश/UPI/कार्ड।  
- **Day close** — दराज का नकद सिस्टम से मिलाएँ; शिफ्ट खत्म पर करें।

### स्टॉक न हो / शॉर्टेज बुक

दवा खोज में स्टॉक 0 हो तो **Shortage book** में जोड़ सकते हैं (मिस सेल)। बाद में Inventory → Shortage book से ऑर्डर प्लान करें।

### शेड्यूल / प्रिस्क्रिप्शन दवाएँ

Schedule H / H1 / X या Prescription required दवाओं पर मरीज़ + डॉक्टर भरें — रजिस्टर के लिए ज़रूरी। सॉफ्टवेयर चेतावनी दे सकता है; कानूनी निर्णय फार्मासिस्ट का है।

## 6. सेल रिटर्न (ग्राहक को वापसी)

सेल्स से **F8** या रिटर्न स्क्रीन खोलें।

### कदम

1. मूल बिल खोजें — इनवॉइस नंबर, नाम, मोबाइल, दवा या QR।  
2. बिल चुनें।  
3. हर पंक्ति पर **वापसी मात्रा** डालें (बेची गई से ज़्यादा नहीं; पहले की रिटर्न घटाकर)।  
4. कारण (वैकल्पिक)।  
5. रिफंड तरीका चुनें (कैश / क्रेडिट नोट आदि)।  
6. प्रोसेस करें।

**नतीजा:** स्टॉक उसी **बैच** में वापस; क्रेडिट नोट बन सकता है।

ऊँची वैल्यू / पॉलिसी ओवरराइड के लिए अतिरिक्त अनुमति लग सकती है। रिटर्न के दिनों की सीमा सेटिंग में होती है।

## 7. परचेज़ (माल अंदर लाना)

**Purchase invoice** — सप्लायर का बिल दर्ज कर स्टॉक बढ़ाना।

### हेडर भरें

1. **सप्लायर** चुनें (ज़रूरी) — नाम टाइप कर सुझाव से चुनें।  
2. **सप्लायर इनवॉइस नंबर** और **तारीख**।  
3. पेमेंट: अभी पूरा / आंशिक / उधार (क्रेडिट)। आंशिक पर कारण पूछ सकता है।

### दवा पंक्तियाँ

| कॉलम | मतलब |
|------|------|
| Item | Enter से खोजें |
| Batch | सप्लायर बैच नंबर (ज़रूरी) |
| Exp M / Exp Y | एक्सपायरी महीना / साल |
| Quantity | खरीदी मात्रा |
| Free | स्कीम/फ्री (स्टॉक बढ़ेगा, बिल वैल्यू में नहीं) |
| Cost | खरीद रेट |
| MRP / Sale | बेचने के रेट |
| GST % | टैक्स |
| Disc % | छूट |

### बिल स्कैन (OCR)

1. **Scan bill** दबाएँ।  
2. एक या **कई पेज** की इमेज चुनें (मल्टी-सेलेक्ट)।  
3. “Scanning…” दिखेगा; फिर फुलस्क्रीन रिव्यू।  
4. सप्लायर नाम जाँचें; हर पंक्ति पर **Pick** से दवा मास्टर से जोड़ें।  
5. **Apply to Purchase** → फॉर्म भर जाएगा।  
6. रेट/बैच जाँचकर **F9 Save**।

**ज़रूरी:** सप्लायर सही चुना हो तभी Save चालू होगा। ACE OLEDB MedWin के लिए है; बिल स्कैन के लिए Windows OCR / Gemini।

### सेव (F9)

स्टॉक बढ़ेगा, सप्लायर लेजर अपडेट, नंबर जैसे `PUR-yyyyMMdd-####`। सेव के बाद लॉक; अनुमति हो तो Unlock।

**Esc** से परचेज़ बिल साफ़ नहीं होता — **New** बटन से नया शुरू करें।

---

## 8. परचेज़ ऑर्डर

यह **ऑर्डर** है, स्टॉक नहीं बढ़ता।

1. सप्लायर चुनें।  
2. दवाएँ और मात्रा डालें।  
3. सेव करें।  
4. माल आने पर **Purchase invoice** में GRN दर्ज करें (PO लिंक हो तो जोड़ें)।

कम स्टॉक रिपोर्ट / शॉर्टेज बुक से ऑर्डर प्लान करें।

---

## 9. परचेज़ रिटर्न (सप्लायर को वापसी)

खराब / गलत / शॉर्ट एक्सपायरी माल **खरीद बिल** के खिलाफ वापस।

1. **F3 / Search bill** से परचेज़ खोजें।  
2. रिटर्न मात्रा डालें।  
3. **F9 Process return**।

स्टॉक घटेगा; सप्लायर क्रेडिट खुलेगा।

**नोट:** सिर्फ़ एक्सपायरी कंपनी को भेजनी हो और हर GRN न खोजना हो तो **Expiry to company** इस्तेमाल करें।

---

## 10. एक्सपायरी टू कंपनी

नज़दीक/एक्सपायर बैच → क्लेम → कंपनी क्रेडिट नोट।

### टैब: Eligible batches

1. **Window** चुनें — Expired only / 30 / 90 दिन आदि।  
2. **Supplier** फ़िल्टर — सिर्फ़ वे सप्लायर जिनके परचेज़ बिल हैं। “No supplier” = मैप न हुए बैच।  
3. **Refresh**।  
4. **Sel** चेकबॉक्स से पंक्ति चुनें; **Claim qty** भरें या **Claim all stock**।  
5. सप्लायर खाली हो तो कॉलम में कंपनी चुनें।  
6. Submit — स्टॉक निकलेगा, क्लेम नंबर (`EXP-…`) बनेगा।

### टैब: Claims / credit notes

कंपनी का क्रेडिट नोट आए तो:

1. क्लेम खोलें।  
2. CN नंबर, तारीख, राशि भरें।  
3. सेव — स्थिति settled हो जाएगी।

---

## 11. इन्वेंटरी (स्टॉक)

### On Hand

लाइव बैच सूची: दवा, बैच, एक्सपायरी, Qty, कॉस्ट, MRP, **लोकेशन (रैक/बिन)**।

- खोज: नाम, साल्ट, बारकोड, रैक, बिन  
- फ़िल्टर: In stock, Low, Near expiry, Expired, Zero  

### Ledger

दवा की आवक-जावक इतिहास (खरीद, सेल, एडजस्टमेंट, ट्रांसफर) और रनिंग बैलेंस।

### Adjustment

फिजिकल काउंट ≠ सिस्टम (कमी/ज्यादा/डैमेज)। दवा + बैच चुनकर सेव — एडजस्टमेंट वाउचर बनता है। अनुमति ज़रूरी।

### Transfer

ब्रांचों के बीच स्टॉक भेजना/पाना (मल्टी-स्टोर)। अनुमति ज़रूरी।

### Shortage book

बिलिंग पर स्टॉक न मिलने वाली दवाओं की सूची। Open → Ordered → Fulfilled। अगले परचेज़ ऑर्डर के लिए उपयोगी।

## 12. मास्टर्स (मास्टर डेटा)

खोज में कम से कम **2 अक्षर** टाइप करें।

### सप्लायर

नाम, GSTIN, ड्रग लाइसेंस, फ़ोन, पता, भुगतान दिन। Active/Inactive।

### ग्राहक

नाम, मोबाइल, प्रकार, पता, **क्रेडिट लिमिट**, बाक़ी। सेल्स और ड्यूज़ में इस्तेमाल।

### डॉक्टर

नाम, रजिस्ट्रेशन, स्पेशलाइज़ेशन, हॉस्पिटल — सेल्स और Schedule रजिस्टर के लिए।

### मैन्युफैक्चरर

दवाई बनाने वाली कंपनी (डिस्ट्रीब्यूटर/सप्लायर से अलग)।

### कर्मचारी

कोड, नाम, पद, फ़ोन आदि।

### दवाएँ (सबसे महत्वपूर्ण मास्टर)

| फ़ील्ड | क्यों ज़रूरी |
|--------|--------------|
| Name * | खोज और बिल प्रिंट |
| Generic / Salt | विकल्प और खोज |
| Brand | प्रदर्शन |
| Barcode | स्कैनर |
| **HSN** | टैक्स (एडिट किया जा सकता है) |
| GST % | बिल पर टैक्स |
| MRP / Purchase / Selling | डिफ़ॉल्ट रेट |
| Reorder level | कम स्टॉक अलर्ट |
| **Location (Rack)** | दुकान में जगह |
| Schedule | H / H1 / X / OTC आदि |
| Prescription required | सेल पर फ़्लैग |
| Status | Inactive = खोज में नहीं |

**सेव** के बाद नई बैच पर रैक मास्टर से कॉपी हो सकता है। बारकोड जनरेट / लेबल प्रिंट / कैमरा स्कैन उपलब्ध।

## 13. अकाउंटिंग (हिसाब)

### Parties

ऊपर रंगीन बॉक्स:

- **Receivable** — कुल ग्राहक बाक़ी  
- **Payable** — कुल सप्लायर देय  
- चुने पक्ष के: Bills, Pending, Total, Due, First/Last due  

नीचे सूची से पक्ष चुनें → दाएँ **Open bills**।  
**Include settled** चेक करें तो चुकाए बिल भी दिखेंगे।  
**Payment / Receipt** बटन से वाउचर स्क्रीन पर जाएँ।

### Customer Dues

बाक़ी वाले ग्राहक → बिल देखें → **Collect** से पैसे लें और रसीद प्रिंट करें।

### Vouchers

पेमेंट / रसीद / खर्च वाउचर। बिल चुनकर राशि लगाएँ।

### Cash Book

तारीख के साथ कैश आवक-जावक और बैलेंस।

### Journal

डबल-एंट्री (अकाउंटेंट के लिए)। रोज़मर्रा में ज़्यादातर सेल्स/परचेज़/Collect काफ़ी हैं।

## 14. रिपोर्ट्स

**Reports** खोलें → रिपोर्ट चुनें → From/To तारीख → **Run**। अनुमति हो तो **CSV / Excel / PDF** एक्सपोर्ट।

| रिपोर्ट | सरल मतलब |
|---------|-----------|
| Sales Report | अवधि की सेल्स |
| Purchase Report | अवधि की खरीद |
| GST Summary | आउटपुट vs इनपुट GST |
| GSTR-1 export | सेल्स से GSTN स्टाइल JSON/Excel (CA जाँच के बाद पोर्टल) |
| GSTR-2B worksheet | खरीद ITC वर्कशीट (आधिकारिक 2B नहीं) |
| Gross Profit | अनुमानित मुनाफ़ा |
| Sales by Medicine | दवा अनुसार बिक्री |
| Schedule H / H1 | निरीक्षण रजिस्टर |
| Stock Valuation | स्टॉक वैल्यू (कॉस्ट पर) |
| Expiry Report | एक्सपायरी रिपोर्ट |
| Low Stock | कम स्टॉक |
| Sale Returns | रिटर्न सूची |

कुछ रिपोर्टों में पंक्ति क्लिक कर बिल खुल सकता है।

## 15. सेटिंग्स

### Company

दुकान का नाम, पता, GSTIN, ड्रग लाइसेंस, PAN, लोगो, **UPI VPA** (बिल पर QR), फ़ुटर।

### Branches / Counters

मल्टी स्टोर / मल्टी काउंटर।

### Preferences

- Near-expiry दिन, लो-स्टॉक थ्रेशहोल्ड  
- इनवॉइस प्रीफ़िक्स  
- डिफ़ॉल्ट बिल पेपर साइज़  
- बिल एडिट अनुमति  
- Gemini (परचेज़ स्कैन)  
- WhatsApp/SMS शेयर  

### MedWin Import

पुराना MedWin `data.mdb` इम्पोर्ट। **पहले बैकअप**।  
कंप्यूटर पर **64-bit Access Database Engine (ACE)** होना ज़रूरी। न हो तो Microsoft से `AccessDatabaseEngine_X64.exe` इंस्टॉल करें; 32-bit Office हो तो `/quiet` से चलाएँ।

### Roles & Users

रोल पर टिक → सेव → यूज़र को **फिर लॉगिन** कराना। काउंटर के लिए अलग **Cashier** यूज़र बनाएँ; Super Admin पासवर्ड साझा न करें।

### My Password / Appearance

अपना पासवर्ड; थीम।

### Backup

- **Backup now** — इस PC पर `.bak`  
- Restore — वर्तमान डेटा बदल देता है; पहले बिलिंग बंद करें  
- ऑटो बैकअप / Google Drive (OAuth)  

### Shop updates

नया Setup उपलब्ध हो तो अपडेट। इंस्टॉलर फ़ाइलें बदलने से पहले ऐप बंद करें।

## 18. रोज़ / हफ़्ते / महीने का काम

### सुबह खोलते समय

1. लॉगिन → काउंटर चुनें।  
2. डैशबोर्ड देखें (एक्सपायरी, कम स्टॉक)।  
3. **Sales** खोलें।

### दिन भर

- सेल्स पर बिल बनाएँ; रेगुलर के लिए **F6**।  
- बॉक्स खुलते ही **Purchase** में बैच + एक्सपायरी सही दर्ज करें।  
- दवा न मिले तो Masters / On Hand पर **Location** जाँचें।

### शाम बंद करते समय

1. खुले पार्क बिल सेव या बंद करें।  
2. **Day close** — कैश मिलाएँ।  
3. साइन आउट।

### हफ़्ते में

- Low stock / Shortage → परचेज़ ऑर्डर।  
- Near expiry → Expiry to company या छूट से बेचें।  
- बैकअप चलाएँ / Drive चेक करें।

### महीने में

- GST रिपोर्ट (GSTR-1 वर्कशीट) CA को दें।  
- Gross profit / Stock valuation देखें।  
- यूज़र पासवर्ड रिव्यू।

## संक्षिप्त याद रखने वाली बातें

1. **F2** = बिलिंग, **F9** = सेव।  
2. स्टॉक = **बैच + एक्सपायरी**।  
3. खरीदते समय बैच/एक्सपायरी गलत = बाद में सेल और एक्सपायरी रिपोर्ट गलत।  
4. उधार सेल = बाद में **Customer Dues / Parties** से वसूली।  
5. रोज़ **डे क्लोज़** और नियमित **बैकअप**।  
6. संदेह हो तो एडमिन या सपोर्ट से पूछें — गलत Unlock/Restore से डेटा खराब हो सकता है।
