PharmaPOS — Installation & update notes
=======================================

Requirements
------------
• Windows 10/11 (64-bit)
• SQL Server Express LocalDB (free). If the installer warns that LocalDB is missing,
  install it from Microsoft, then launch PharmaPOS.

Fresh install
-------------
On first launch, PharmaPOS restores a master-data backup that includes:

  • Medicines catalogue (including salts / generic names)
  • Manufacturers and medicine categories
  • Suppliers (balances reset to zero)
  • MedWin medicine mappings (if present)
  • System setup: roles, admin user, chart of accounts, return reasons

It does NOT include shop-specific data:

  • Customers / patients, doctors, employees
  • Stock batches / inventory quantities
  • Sales, purchases, returns, or accounting journals

1. Enter the store code provided by the vendor (one-time per PC).
2. Login: admin / Admin@123 (you will be prompted to change the password).

Updating an existing shop
-------------------------
Run the newer PharmaPOS-Setup-x.y.z.exe on the shop PC (or accept the in-app
update prompt). This replaces program files only.

Preserved on upgrade:
  • Shop LocalDB database (sales, stock, customers, settings)
  • Existing appsettings.json / Production settings
  • Existing Data\ master backup file (if already present)

After update, reopen PharmaPOS. EF migrations apply automatically on startup.

Data location
-------------
Database files live under:
  %LocalAppData%\PharmaPOS\Data\
